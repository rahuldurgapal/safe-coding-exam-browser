# 🪟 Windows Applications (Safe Exam Browser)

Download and run on any Windows 10 / 11 computer:

---

### 1. ⚡ Portable Version (Recommended - Zero Installation)
* **File:** `CodingExamSafeBrowser 1.0.0.exe`
* **How to use:** Download and double-click to run immediately. No installation or administrator permissions required.

---

### 2. 📦 1-Click Installer Setup
* **File:** `CodingExamSafeBrowser Setup 1.0.0.exe`
* **How to use:** Double-click to install. It automatically creates a Desktop / Start Menu shortcut and launches the application.

---

### 🛡️ First-Time Windows SmartScreen Notice
When opening for the first time, Windows Defender SmartScreen may display:
> *"Windows protected your PC - Microsoft Defender SmartScreen prevented an unrecognized app from starting"*

**Steps to run:**
1. Click **`More info`** (or *अतिरिक्त जानकारी*)
2. Click **`Run anyway`** (or *फिर भी चलाएं*)

*This prompt appears only on the first run because the app is a custom exam browser built for your institution without a $400/yr corporate EV certificate.*

---

### 🔒 Built-in Security & Anti-Cheat Features
* **Anti-VM Protection:** Strictly blocks execution inside Virtual Machines (Oracle VM VirtualBox, VMware, Hyper-V, QEMU). Candidates must run directly on physical hardware (Host OS).
* **OS Kiosk Lockdown:** Locks screen, disables Alt+Tab, Task Switcher, and developer inspect tools.
* **Dual-Monitor Detection:** Prevents external HDMI screens or secondary monitors.
* **Zero-Hang Exit:** Press **`Ctrl + Q`**, **`Alt + F4`**, or **`Esc`** once to open the exit confirmation popup (press again to close it and resume).
